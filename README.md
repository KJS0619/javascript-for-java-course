# 자바 개발자를 위한 JavaScript 입문

> Java 백엔드 개발자가 JavaScript를 빠르게 익히기 위한 실전 안내서

## 이 책의 대상

- Java/Spring 백엔드 개발자
- JavaScript를 처음 배우거나 체계적으로 정리하고 싶은 분
- React, Vue, Node.js를 배우기 전 기초를 다지고 싶은 분

## 목차

| 장 | 제목 | 핵심 내용 |
|----|------|----------|
| 0 | 오리엔테이션 | 학습 목표, 환경 설정 |
| 1 | JavaScript 첫걸음 | Java와의 근본적 차이 |
| 2 | 변수와 타입 | 동적 타입, var/let/const |
| 3 | 함수의 모든 것 | 화살표 함수, 클로저 |
| 4 | 객체와 배열 | 프로토타입, 고차 함수 |
| 5 | 클래스와 모듈 | ES6 클래스, import/export |
| 6 | 비동기 프로그래밍 | Promise, async/await |
| 7 | DOM과 이벤트 | 웹 페이지 조작 |
| 8 | 모던 생태계 | npm, 번들러, TypeScript |
| 9 | 실전 프로젝트 | Spring Boot API 연동 |

## 특징

- **Java 비교 중심**: 매 개념마다 Java 코드와 비교
- **실습 중심**: 각 장마다 직접 실행해볼 예제
- **실전 지향**: Spring Boot와 연동하는 프로젝트 포함

## 환경

- Node.js 18+
- 브라우저 개발자 도구
- VS Code (권장)
